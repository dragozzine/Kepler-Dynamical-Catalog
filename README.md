# Kepler-Dynamical-Catalog
Codes and data for the Kepler Dynamical Catalog and Kepler Multis Dynamical Catalog (KMDC) generated through photodynamical modeling (with PhoDyMM) of Kepler Space Telescope data. Shared to enable a wide variety of exoplanet architectures, demographics, dynamics, interiors, and other studies. See Jones, Ragozzine, & Fabrykcy for details. Any use of this data should also cite that paper and perhaps others. Data in this repository are under a CC-BY-4.0 license.
