# KDC Column Sources

Each column in the KDC corresponds to a study --- if you use that column, please cite the relevant study! For the mapping of columns to sources, see Provenance.md.

## Sources

Regardless of the column used, any work that uses the KDC should cite the following two sources:
- Jones et al. in preparation [proper citation url]. This study ran a photodynamical analysis script, PhoDyMM, on most of the Kepler multiplanet systems. The raw posteriors for these systems were computed by this study. 
- Blodgett & Ragozzine in preparation [proper citation url]. This study did most of the post-processing work for the PhoDyMM analysis performed by Jones et al., turning its output into a useable format and folding in the entirety of the Kepler catalog.
